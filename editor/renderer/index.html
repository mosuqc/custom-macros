    Syntax Helper

    File Structure

    Every .cmcm file starts with a NAME: line, followed by numbered steps.

    NAME: MyMacro
1. Insert:Text:hello world
2. CardMirror:Bold
3. Insert:Date:m.dd.yy

    Step numbers are cosmetic — order is determined by line position. Lines starting with # are comments.

    Insert Steps

    Insert:Text:<content> Insert literal text. Everything after the second colon is the content, including trailing spaces.
    Insert:Date:<format> Insert the current date using format tokens (see Date Tokens below).
    Insert:Newline Insert a line break (new paragraph).
    Insert:Clipboard Paste the current clipboard text content.
    Insert:Prompt:<message> Show a dialog asking the user for input, then insert their response. Cancelling aborts the macro.
    Insert:Counter:<name> Insert an auto-incrementing number. Each named counter persists across macro runs.
    Insert:!<varname> Insert the current value of a variable (see Variables below).

    Date Tokens

    Used inside Insert:Date: format strings. Tokens are replaced with the current date; all other characters pass through literally.

    mMonth without leading zero (1–12)
    mmMonth with leading zero (01–12)
    dDay without leading zero (1–31)
    ddDay with leading zero (01–31)
    yyTwo-digit year (26)
    yyyyFour-digit year (2026)
    MonAbbreviated month (Jan, Feb, ...)
    MONAbbreviated month uppercase (JAN, FEB, ...)
    MonthFull month name (January, February, ...)
    MONTHFull month name uppercase (JANUARY, ...)

    Example: Insert:Date:m.dd.yy → 8.11.26

    CardMirror Commands

    CardMirror:<label> fires a CardMirror command by its display label.

    CardMirror:Bold
CardMirror:Apply Block Style
CardMirror:Italic

    The autocomplete dropdown shows all 168 commands with their keybindings. Commands marked no keybind currently cannot be executed (pending a CardMirror API update).

    Variables

    Variables are prefixed with ! and set with the SET keyword.

    SET !name = "value"
SET !count = 5
SET !next = !count + 1
Insert:!name
    SET !var = "text"Set variable to a string
    SET !var = 42Set variable to a number
    SET !var = !otherCopy value from another variable
    SET !var = !x + 1Arithmetic: add
    SET !var = !x - 1Arithmetic: subtract
    SET !var = COUNT(...)Count elements (see Counting below)

    Conditionals

    Use IF / ELIF / ELSE / END to run steps only when conditions are met.

    IF DocumentName.contains("2AC")
  SET !speech = "1NC"
ELIF DocumentName.contains("2NC")
  SET !speech = "2AC"
ELSE
  SET !speech = "Arg"
END

    Conditions

    Conditions are used inside IF, ELIF, and WHILE statements.

    Element.contains("text") True if the element's heading contains the given text
    Nearby.Element.contains("text") True if a nearby sibling element contains the text
    Element.contains(!var) Test against a variable's value instead of a literal
    !var = "text" Variable equals a string
    !var > 5 Variable is greater than a number
    !var < 10 Variable is less than a number

    Combine conditions with AND and OR:

    IF Pocket.contains("2AC") OR DocumentName.contains("2AC")
IF !count > 0 AND !count < 10

    AND binds tighter than OR: A AND B OR C means (A AND B) OR C.

    Elements

    These are the structural element types you can reference in conditions and COUNT expressions:

    Pocket Hat Block Tag Analytic Cite CiteParagraph CardBody Text Underlined Highlighted Emphasized DocumentName

    Note: DocumentName works now via the existing API. Other element queries (Pocket, Hat, Block, etc.) require a CardMirror API update and currently evaluate to false.

    Loops

    REPEAT runs a block a fixed number of times. WHILE runs as long as a condition is true.

    REPEAT 3
  Insert:Text:hello
END

WHILE !count > 0
  Insert:!count
  SET !count = !count - 1
END

    Use BREAK to exit the innermost loop early. Loops are capped at 10,000 iterations as a safety limit.

    Counting

    COUNT expressions count document elements. Use them inside SET to store the result.

    COUNT(Blocks)Count all Blocks in the document
    COUNT(Nearby.Blocks)Count sibling Blocks near the cursor
    COUNT(Blocks.containing("text"))Count Blocks whose heading contains "text"
    COUNT(Nearby.Blocks.containing(!var))Count nearby Blocks containing a variable's value

    Combine with arithmetic for numbering:

    SET !num = COUNT(Nearby.Blocks.containing(!speech)) + 1

    Note: COUNT requires a CardMirror API update to return real values. Currently returns 0 — use + 1 as a floor.

    Full Example

    NAME: LBLBlock
1. SET !speech = "Arg"
2. IF DocumentName.contains("2AC")
3.   SET !speech = "1NC"
4. ELIF DocumentName.contains("2NC")
5.   SET !speech = "2AC"
6. ELIF DocumentName.contains("1AR")
7.   SET !speech = "Arg"
8. END
9. SET !flowNum = COUNT(Nearby.Blocks.containing(!speech)) + 1
10. CardMirror:Apply Block Style
11. Insert:Text:AT:
12. Insert:!speech
13. Insert:Text: -
14. Insert:!flowNum

    This macro applies a Block heading, then inserts a label like AT:1NC -1, auto-detecting the speech name from the document title and numbering the block based on nearby siblings.
